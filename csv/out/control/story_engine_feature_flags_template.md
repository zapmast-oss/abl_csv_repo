# Story Engine Feed 3 Feature-Flag Template

| Flag | Safe default |
|---|---:|
| `enable_feed3_evidence_preview` | `true` |
| `enable_feed3_rank_adjustment` | `false` |
| `enable_feed3_new_candidates` | `false` |
| `enable_owner_front_office_signals` | `false` |
| `enable_best_game_discovery_signals` | `false` |
| `enable_historical_fan_interpretation` | `false` |

Copy these values into a date-specific configuration only after that newsroom date has completed source capture, preflight, candidate generation, Feed 3 promotion, and enrichment-overlay preparation.

Evidence preview is append-only. Ranking, candidate creation, owner/front-office automation, best-game ranking signals, and historical fan interpretation remain disabled.
